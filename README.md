# Book Sales & Ratings Analysis
An Excel-based data analysis project focused on evaluating book sales performance, customer ratings, pricing patterns, and genre popularity to identify business trends and support data-driven decision-making. The analysis explored relationships between pricing, customer engagement, review activity, and book categories using Pivot Tables, charts, and summary statistics to generate actionable business insights and recommendations.
